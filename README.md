# 级联阴影分割

一个把摄像机视锥切成多级阴影贴图、并保证级间衔接无缝的分割器。仅使用 Python
标准库，无第三方依赖；`data/split.json` 保持原样不改动。

## 保留签名

- `Cascade`（原有四字段 `index / near / far / resolution` 不变，追加带默认值的
  `texel_world`、`align_error`，旧构造方式完全兼容）
- `split_cascades(near, far, levels)`
- `tighten_bounds(cascades, cam)`
- `blend_region(a, b, t)`

## 分割算法

`split_cascades` 采用**对数/均匀混合分割**（hybrid log-uniform，混合系数
`LAMBDA = 0.5`，取纯对数与纯均匀的中点）：

```
log_i     = near * (far / near) ** (i / n)
uniform_i = near + (far - near) * i / n
d_i       = 0.5 * log_i + 0.5 * uniform_i
```

- 首端强制为 `near`、末端强制为 `far`，相邻级 `cascades[i].far ==
  cascades[i+1].near`，区间不重叠、不留空隙。
- 每级贴图分辨率固定为 **1024**。
- 世界空间精度定义为 `precision = (far - near) / resolution`，即一个纹素覆盖
  的世界深度长度；数值越大越粗糙。混合分割下级联跨度逐级增大，因此精度逐级
  递远（变粗糙）。

## 级间衔接（过渡区）

相邻两级在共享边界附近取宽度为该级深度跨度 **10%**（`BLEND_FRACTION = 0.1`）
的对称过渡区。`blend_region(a, b, t)` 用 smoothstep 给出本级与下一级的权重：

```
u = clamp((t - a) / (b - a), 0, 1)
s = u*u*(3 - 2u)
w_this = 1 - s,  w_next = s
```

- 任意采样点 `w_this + w_next == 1.0`，亮度不发生断层；
- smoothstep 在过渡区两端导数为 0，与级内常量权重平滑相接；
- 零宽度过渡区按阶跃处理，结果仍确定且权重和为 1。

## 纹素对齐

`tighten_bounds(cascades, cam)` 把每级近平面 **floor**、远平面 **ceil** 到该级
纹素网格（纹素长度 `texel = (far - near) / resolution`，网格原点取
`cam["origin"]`，默认 0）。吸附后仍完整覆盖原区间；网格原点固定后边界不再随
相机微小移动而抖动（texel snapping）。

- 吸附前两端偏差在 `(-1, 1]` 纹素以内（近平面 `[0, 1)`、远平面 `(-1, 0]`）；
- 吸附后 `alignment_error` 残余偏差只来自浮点舍入，本机实测 **0.0 纹素**，
  保证值 < 1e-9 纹素（远平面 1e12 的极端场景仍满足）。

## 边界情况

| 情况 | 行为 |
| --- | --- |
| 级数变化（1～任意正整数） | 单级时整段 `[near, far]` 一级覆盖；多级时严格首尾相接 |
| 近平面极小（如 1e-6） | 对数项在 log 空间计算，不产生下溢，区间仍严格递增 |
| 远平面极大（如 1e12） | 全程 `math.isfinite` 校验 + float 运算，确定区间；`inf`/`nan` 输入抛 `ValueError` |
| 非法输入 | `near <= 0`、`far <= near`、`levels < 1`、非有限数均抛 `ValueError` |

## 确定性

分割与序列化不含随机量、不依赖字典遍历顺序；JSON 以 `sort_keys` + 固定分隔符
写出。同一输入两次 `split_cascades` 结果相等，两次 CLI 输出文件逐字节一致
（已用 `diff` 核验）。

## 实测结果

命令：

```
python -m cascade.cli data/split.json --levels 4 --out cascades.json
```

输入 `near=0.5, far=80.0, resolution=1024`，4 级。
